# **Git Clone Instructions**

>[!IMPORTANT]
>This guide will show you how to git clone a repository. This is essentially taking the repository and its contents, and putting it into a folder on your local device.


## **STEP 1**


We first go to this website :point_right: https://git-scm.com/install/windows


>[!NOTE]
>Our first step is to download git. Reminder that you NEED to download the respective operating system download. (Your work computer is most likely windows if you are at DAA). Select the 64 bit downloader as seen in the image below.

With the shell in the correct directory, we now need to copy the repository path. In github (in the specific repo), click code -> copy http.
